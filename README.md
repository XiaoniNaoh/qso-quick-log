# 📻 通联速记 · QSO Quick Log

面向业余无线电爱好者的通联记录与电子 QSL 工具。打开即用，数据留在本机，记一条 QSO 大约十几秒——比读完这份 README 快。

> 呼号一输，逐项点选，点「保存并继续」。一条通联就记好了，没有人需要为此鼓掌。

**在线地址：https://xiaoninaoh.github.io/qso-quick-log/**

**当前版本：2.7.1**

## 项目简介

一个单文件网页应用，目标是让日志这件事「没有负担」：

- **功能优先**：记录、信号报告、电子 QSL 一气呵成，不堆砌功能；
- **轻量**：一个 HTML 文件，不用安装、不用注册、不占内存；
- **隐私**：数据只存在本机浏览器，不经过任何服务器——没有服务器，也就没有「我们郑重承诺绝不出售您的数据」的台词，因为根本没地方可卖；
- **跨端**：电脑、手机、平板通用，支持离线与 PWA 安装。

## 功能特性

### ✍️ 快记流程

- 呼号起头，逐项填写，老呼号自动带出上次信息；
- 频率自动换算波段（也认 kHz，比如 `14074`）；
- 时间按 CST 录入，UTC 自动换算；
- 桌面端 `⌘/Ctrl + Enter` 随时保存。

### 🔤 呼号智能识别

- 输入呼号自动识别：中国呼号按分区显示省份，常见前缀显示 DXCC 归属；
- 第一次通联的呼号会客客气气地标上「首次通联 NEW」。

### 🔁 中继台库

- 常用中继台一键保存，填下行频率和上/下差偏移，上行自动算好——数学由程序完成，你可以放心喝茶；
- 首页记录过的新中继台自动入库，频率、差频、哑音一次带齐；
- 同频率的中继台自动合并，尽量避免收藏夹里出现两个一模一样的。

### 📊 双向信号报告

- 「我给对方 / 对方给我」的 R、S 分开记录；
- 满格 S9 还能附加 +dB，CW 模式下 T 音调会自动出现，不用你提醒它。

### 🃏 电子 QSL 卡片

- 一键生成可打印的电子卡片，卡片上的内容可以直接点改——改完记得它还是卡片；
- 导出后自动盖上「QSL ✓」章，可打印，也可存成 PDF。

### 💾 数据与备份

- 工具条「备份」打开备份中心：**完整备份**（记录 + 中继台 + 设置）一键导出 JSON，或生成压缩备份链接发到任意设备；
- 工具条「导入」、拖拽导入与「通过链接导入」统一走「合并 / 替换」确认流程，兼容旧版纯记录导出；
- 自动备份：在「设置 → 关于」或首次引导里选每天 / 每周 / 每月，本机自动留存完整快照，误删也能找回；更新应用不会重置你的选择；
- 另支持导出 **ADIF**（日志软件通用）、**CSV**（表格软件直接打开）；
- 删除可以撤销：误删后 6 秒内可一键恢复。6 秒足够你冷静下来想清楚是不是真要删。

### ⚙️ 个性化

- 首次启动有四步引导：欢迎、填呼号、挑主题、上手。没有第五步，不用等；
- 我的呼号、默认频率 / 模式、设备、QTH、Grid 都能配置；
- 界面风格提供「靛蓝」「苔青」「琥珀」「极光」「深海」「素白」六套主题，深浅色都适配。如果觉得不够，设置里还有——没有了，就这六套；
- 深色模式默认跟随系统，也可以手动固定；
- 自动检查更新每 30 天一次。不想被打扰的话，设置里可以关掉，它不会记仇。

## 安装与使用

### 🖥️ 桌面端

浏览器打开即用。Chrome / Edge 地址栏的「安装」按钮能把它变成桌面应用——本质上还是一个网页，但看起来像 App，体验也像，这就够了。

### 📱 iPhone / iPad

1. 用 Safari 打开在线地址；
2. 点「分享」→「添加到主屏幕」；
3. 从桌面图标点开，全屏、离线可用。

### 🤖 安卓

1. 用 Chrome 打开在线地址；
2. 右上角菜单 →「添加到主屏幕 / 安装应用」。

## 🔒 数据与隐私

- 记录只存在本机浏览器（localStorage），不经过任何服务器；
- 清理浏览器数据等于清空记录——所以请定期导出备份，这不是吓唬你，这是提醒；
- 换设备：导出 JSON 或生成备份链接，到新设备合并 / 替换即可。

## 技术架构

- 单文件 HTML / CSS / JS，无框架、零构建，一个文件装下整个项目；
- 存储：浏览器 `localStorage`；
- 字体：Helvetica Neue / Helvetica / Arial 无衬线体系，中文跟随系统；
- PWA：`manifest.json` + Service Worker，支持离线缓存、主屏幕安装。
