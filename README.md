# 📻 通联速记 · QSO Quick Log

面向业余无线电爱好者的**通联记录与电子 QSL 工具**：打开即用、数据留在本机、记一条 QSO 只要十几秒。

> 呼号一输，逐项点选，点一下「保存并继续」——一条通联就记好了。

**在线地址：<https://xiaoninaoh.github.io/qso-quick-log/>**

## 项目简介

通联速记（QSO Quick Log）是一个单文件网页应用，目标是为火腿们提供一种「没有负担」的日志方式：

- **功能优先**：记录、信号报告、电子 QSL 一气呵成，不堆砌功能；
- **轻量**：一个 HTML 文件，无需安装、无需注册、不占内存；
- **隐私**：所有数据仅保存在本机浏览器，不经过任何服务器；
- **跨端**：电脑、手机、平板通用，支持离线使用与 PWA 安装。

## 功能特性

### ✍️ 快记流程

- 呼号起头，逐项填写，老呼号自动带出上次信息；
- 频率自动换算波段（也认 kHz，如 `14074`）；
- 通联时间按 CST 录入，UTC 自动换算；
- 桌面端按 `⌘/Ctrl + Enter` 随时保存。

> 手机端不会擅自弹键盘：点哪个输入框，键盘才会出现；回车键也不会自动跳格或误保存。

### 🔤 呼号智能识别

- 输入呼号自动识别：中国呼号按分区显示省份，常见前缀显示 DXCC 归属；
- 从未通联过的呼号自动标记「首次通联 NEW」。

### 🔁 中继台库

- 常用中继台一键保存，填下行频率 + 上/下差偏移，自动算好上行频率；
- 首页记录的新中继台自动入库，频率、差频、哑音一次带齐；
- 同频率的中继台自动合并，避免重复。

### 📊 双向信号报告

- 「我给对方 / 对方给我」的 R 与 S 分开记录；
- 满格 S9 可附加 +dB，CW 模式自动出现 T 音调。

### 🃏 电子 QSL 卡片

- 一键生成可打印的电子卡片，卡片内容可直接点改；
- 导出后自动盖上 QSL ✓ 章，支持打印或存为 PDF。

### 💾 数据与备份

- 导出 **ADIF**（日志软件通用）、**CSV**（表格软件直接打开）、**JSON**（完整备份）；
- 支持拖拽导入与「备份链接」跨设备恢复（合并或替换）；
- 删除可撤销：误删后 6 秒内可一键恢复。

### ⚙️ 个性化

- 首次启动提供 3 步引导，先填好默认信息；
- 我的呼号、默认频率 / 模式、设备、QTH、Grid 定位均可配置；
- 界面风格可选「经典 · 靛蓝」「信笺 · 鼠尾草」「日暮 · 琥珀」「极光 · 紫」四套主题，深浅色均适配；
- 深色模式自动跟随系统，也可手动固定。

## 安装与使用

### 🖥️ 桌面端（Windows / macOS / Linux）

- 浏览器打开即用；Chrome / Edge 地址栏的「安装」可将其变为桌面应用。

### 📱 iPhone / iPad

1. 用 Safari 打开在线地址；
2. 点「分享」→「添加到主屏幕」；
3. 桌面图标点开即全屏，离线也能使用。

### 🤖 安卓

1. 用 Chrome 打开在线地址；
2. 右上角菜单 →「添加到主屏幕 / 安装应用」。

## 🔒 数据与隐私

- 记录仅存于本机浏览器（localStorage），不经过任何服务器；
- 清理浏览器数据即清空记录，请定期导出备份；
- 换设备：导出 JSON 或生成备份链接，在新设备合并 / 替换即可。

## 技术架构

- 单文件 HTML / CSS / JS，无框架、零构建；
- 存储：浏览器 `localStorage`；
- 字体：Helvetica Neue / Helvetica / Arial 无衬线体系，中文跟随系统；
- PWA：`manifest.json` + Service Worker，支持离线缓存、主屏幕安装与快捷方式。
