# 通联速记 · QSO Quick Log

业余无线电（Ham Radio）通联快速记录工具。单文件网页应用，打开即用、无需安装、无需注册，电脑与手机浏览器均可直接使用；支持「添加到主屏幕 / 安装为应用」，全屏运行，体验接近原生 App。

**在线地址：<https://xiaoninaoh.github.io/qso-quick-log/>**

## 支持的设备与使用方式

### 电脑（Windows / macOS / Linux）

- 用 Chrome、Edge、Firefox 或 Safari 打开在线地址即可使用；
- Chrome / Edge 地址栏右侧会出现「安装」按钮，点击后安装为桌面应用，独立窗口运行；
- 键盘流操作：从「呼号」开始，`Enter` 逐项下移，全程可脱离鼠标。

### iPhone / iPad

1. 用 Safari 打开在线地址；
2. 点底部「分享」→「添加到主屏幕」；
3. 桌面上出现「通联速记」图标，点开即全屏运行。

### 安卓手机

1. 用 Chrome 打开在线地址；
2. 点右上角菜单 →「添加到主屏幕」或「安装应用」；
3. 图标出现在桌面，独立全屏运行。

## 功能特点

### 快速记录

- 从「呼号」开始打字，`Enter` 逐项下移，最后一项按 `Enter` 即保存并开始下一条；
- 老呼号自动带出上次通联信息；
- 频率自动换算波段，支持直接输入 kHz（如 `14074`）；
- 模式、RST、设备、天线、功率均可点选，减少打字；
- 通联时间按 CST 录入，自动换算 UTC 保存。

### 信号报告

- 分「我给对方 / 对方给我」双向记录 R 与 S；
- 选 S9 后可附加 +dB；
- CW 模式自动出现 T 音调字段。

### 电子 QSL 卡片

- 点记录右侧「QSL」生成电子卡片，可打印或存为 PDF；
- 导出后自动打上 QSL ✓ 标签。

### 数据管理

- 导出 **ADIF**（标准电台日志格式，兼容主流日志软件）；
- 导出 **CSV**（Excel / Numbers 可直接打开）；
- 导出 / 导入 **JSON**（完整备份，用于跨设备同步）；
- 按呼号、QTH、姓名、设备搜索历史通联；
- 设置中可一键清空全部记录。

### 个性化设置

- 我的呼号、默认频率 / 模式 / 信号报告；
- 我方设备、天线、功率、QTH、Grid 网格定位（用于生成 QSL 卡片）；
- 深色模式自动跟随系统，也可手动切换。

## 数据与隐私

- 所有记录仅保存在**本机浏览器**（localStorage），不会上传到任何服务器；
- 请定期导出 ADIF / CSV / JSON 备份，清理浏览器数据会清空记录；
- 跨设备同步：任一端导出 JSON 备份，用隔空投送 / 微信 / 网盘传输到另一端，再点「导入」合并。

## 部署与更新

纯静态站点，无构建步骤，任意静态托管平台均可：

- 本仓库：推送 `main` 分支后，GitHub Pages 自动更新；
- 其他平台：把 `index.html`、`manifest.json`、图标一并拖入 Netlify Drop / Vercel 等即可。

## 技术说明

- 无框架、无构建工具的单文件 HTML 应用；
- 数据持久化：浏览器 `localStorage`；
- 字体：Google Fonts（Anton / Martian Mono / Inter / Noto Sans SC）；
- PWA 能力：`manifest.json` + `apple-touch-icon`，支持 iOS「添加到主屏幕」全屏模式与桌面安装。
